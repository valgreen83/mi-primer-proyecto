# mi-primer-proyecto

Mi primer repositorio en GitHub, creado para aprender a trabajar con Git y con pull requests.

## Cómo obtener una copia

```bash
git clone https://github.com/valgreen83/mi-primer-proyecto.git
```

## Cómo contribuir

1. Crea una rama nueva para tu cambio: `git switch -c nombre-de-la-rama`
2. Haz tus cambios y guárdalos con un commit.
3. Sube la rama a GitHub y abre un pull request para que se revise.
